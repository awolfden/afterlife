# Documentation image provenance

All documentation images are local, script-free SVGs. No external images, fonts, tracking URLs, real session labels or device identifiers are embedded.

- `../../preview/afterlife/disconnected.svg`: existing original Afterlife artwork. The SVG includes a preview prompt; the firmware renders its prompt in the native font and adds a Settings label. It is artwork, not a photograph.
- `ghost-family.svg`: arranged from the original purple ghost in `../../preview/index.html` / `../../preview/style.css` and the five original SVGs in `../../preview/ghost-family/`. Drawing paths and colors are retained; identifiers/CSS classes are namespaced to prevent collisions, with layout and labels added. This is an artwork lineup, not a framebuffer capture or a live roster.
- `settings.svg`: a manually assembled illustration using labels, row coordinates and default values from `../../firmware/render/settings-scene.h`. The system monospace font approximates the device Font0 and is not bundled. This is not a pixel-accurate screenshot, a scrolling animation, or evidence of physical performance.

These documentation compositions are original project work under the repository MIT license. Existing dependency/font notices remain in `../../THIRD_PARTY_NOTICES.md`. Firmware assets were not regenerated or changed to create these images.

Real-device photos and a scrolling recording can be added later with the owner's permission and a review for private labels/background information. They are not included in this preview.
